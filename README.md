# NextStep — Career Quiz App

WEBD3100 · NSCC Fall 2026 · Instructor: Bill Kowalski

A five-team class project. Each team owns one component of a career-matching app that helps users find jobs aligned with their skills and interests, then shows them what to do next.

## Hub

The team coordination dashboard lives at `hub/index.html` and is deployed to GitHub Pages. It reads each team's `status.json` automatically — open it to see where the project stands.

**Update your status:** edit `your-team-folder/status.json`, push to your branch, open a PR to `main`.
